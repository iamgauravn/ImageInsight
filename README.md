# ImageInsight
ImageInsight is a full stack web application built using ASP.NET Core, SQL Server, and Angular. The system allows users to upload images, extract structured data from them, and manage that data based on role based permissions.  The backend follows clean architecture principles with a clear separation between Domain, Application, Infrastructure, and API layers. Authentication is handled using JWT, and authorization is implemented using a role and permission based access control system. Admin users can create accounts, assign roles, generate credentials, and control what actions each user can perform such as view, edit, update, or delete extracted data.  The database layer is fully managed using stored procedures and ADO.NET, ensuring predictable performance and strong control over data access. The frontend is built with Angular and includes route guards and UI level permission checks for a smooth and secure user experience.  This project demonstrates real world practices such as layered architecture, RBAC, secure authentication, and scalable backend design.
